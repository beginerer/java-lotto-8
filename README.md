# java-lotto-precourse


### 기능 요구사항
- 로또 번호의 숫자 범위는 1~45까지이다.
	- 로또 범위를 벗어난 숫자가 존재한다면 예외가 발생한다.
	- 보너스 번호가 당첨번호와 중복되면 예외가 발생한다.
	- 보너스 번호가 로또 번호 범위를 벗어나면 예외가 발생한다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
	- 중복된 번호가 존재한다면 예외가 발생한다.
	- 중복되지않은 번호가 6개가 아니라면 예외가 발생한다.
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
	- 구입 금액이 음수라면 예외가 발생한다.
	- 구입금액이 로또 가격에 나누어 떨어지지 않는다면 예외가 발생한다.
